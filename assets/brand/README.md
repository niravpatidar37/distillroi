# distillroi brand assets

The mark is a **funnel with a single drop**: a large model's behaviour, distilled into a small one. The drop and
the liquid level are copper, as in a copper still; "roi" in the wordmark carries the same accent.

| File | Use |
|---|---|
| `logo.svg` / `logo-dark.svg` | Lockup (mark + wordmark) for light / dark backgrounds. README header. |
| `icon.svg` / `icon-dark.svg` | Mark alone, transparent background. |
| `favicon.svg`, `favicon-32.png` | Browser tab / docs favicon (own dark tile, works on light and dark tabs). |
| `favicon-16.svg`, `favicon-16.png` | Hand-hinted 16 px variant on the pixel grid. |
| `avatar.svg` → `avatar-512.png` | Square, opaque avatar (social / org). |
| `social-preview.svg` → `social-preview.png` | Repository social preview, 1280×640, opaque (Settings → Social preview). |

## Colors

| Token | Hex | Contrast | Use |
|---|---|---|---|
| Ink | `#14110F` | 18.8:1 on `#FFFFFF` | Mark and wordmark on light backgrounds; tiles; social background |
| Snow | `#F5F0E8` | 16.7:1 on `#0D1117` | Mark and wordmark on dark backgrounds |
| Copper (light) | `#9C4A1A` | 6.2:1 on `#FFFFFF` | Drop, level and "roi" on light backgrounds |
| Copper (dark) | `#F0975A` | 8.4:1 on `#0D1117` | Drop, level and "roi" on dark backgrounds; demo GIF accents |

The build script checks every pairing against GitHub's light (`#FFFFFF`) and dark (`#0D1117`) backgrounds and
fails below WCAG's 3:1 minimum for graphics.

## Usage

- Keep clear space around the lockup of at least the height of the drop.
- Below 120 px wide, use the mark alone; below 24 px, use the favicon variants.
- Do not recolor, stretch, rotate or set the wordmark in another font. Use the dark variants on dark backgrounds.

## Rebuilding

All assets are generated by `tools/build_brand.py`, so they are reproducible and reviewable as code:

```sh
cargo install resvg --locked --version 0.48.1   # PNG export
uv run assets/brand/tools/build_brand.py
```

The script fetches IBM Plex Mono 1.1.0 from its official GitHub release, verifies the archive's SHA-256,
outlines the wordmark (so the SVGs need no font), checks color contrast, rejects any SVG containing scripts,
event handlers, `foreignObject` or external references, and renders the PNGs with resvg. The downloaded font is
cached in `tools/.cache/` and git-ignored.
